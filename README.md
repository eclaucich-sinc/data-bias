# Data Bias Playground

An interactive framework for understanding and visualizing how systemic biases manifest in machine learning datasets and models.

The playground allows to choose from different bias mechanisms and generate a synthetic dataset with this bias injected.

## Notation

We use a causal framework for data generation, relying on the following standard notation:

* **$S \in \{0, 1\}$**: The binary **Sensitive Attribute** (or Group). 
  * `1` = Privileged Group
  * `0` = Disadvantaged Group
* **$Y \in \{0, 1\}$**: The binary **Target Label**.
  * `1` = Positive Outcome
  * `0` = Negative Outcome
* **$X_y \in \mathbb{R}$**: The **Global Predictive Feature**. A continuous feature derived primarily from the true label $Y$.
* **$X_s \in \mathbb{R}$**: The **Proxy Feature**. A continuous feature derived primarily from the sensitive attribute $S$.

## Bias Mechanisms

The playground supports injecting several distinct forms of bias independently:
* **Label Bias ($S \rightarrow Y$):** Positives in the Disadvantaged group are unfairly flipped to Negatives in the training data.
* **Task Difficulty ($S \rightarrow X_y$):** The predictive features ($X_y$) for the Disadvantaged group are made significantly noisier and harder for a model to learn from.
* **Global Feature Predictivity ($Y \rightarrow X_y$):** The global signal-to-noise ratio of the features. As features become noisier overall, models are forced to rely on proxies.
* **Proxy/Group Separability ($S \rightarrow X_s$):** The degree to which the proxy feature $X_s$ perfectly separates the Privileged and Disadvantaged groups.
* **Base Rate Difference:** Discrepancies in the underlying prevalence of the positive outcome between the two groups.

## Sigmas and AUC

The underlying ground truths ($Y$ and $S$) are **Bernoulli** distributions. However, the features ($X$) are continuous, generated by adding **Gaussian noise** to the Bernoulli labels.

For example, $X_y$ is generated as:  

$$ X_y = Y + \mathcal{N}(0, \sigma_y^2) $$

Because the features are Gaussian, the theoretical Area Under the ROC Curve (AUC) for distinguishing between two Normal distributions with means $\mu_1, \mu_0$ and the same standard deviation $\sigma$ is:  

$$ AUC = \Phi\left( \frac{\mu_1 - \mu_0}{\sigma \sqrt{2}} \right) $$

*(Where $\Phi$ is the Cumulative Distribution Function of the standard normal distribution).*

Because we defined our distributions such that Positives ($Y=1$) have a mean of $\mu_1 = 1$, and Negatives ($Y=0$) have a mean of $\mu_0 = 0$, the formula simplifies to:  

$$ AUC = \Phi\left( \frac{1 - 0}{\sigma \sqrt{2}} \right) = \Phi\left( \frac{1}{\sigma \sqrt{2}} \right) $$

### The Realistic Baseline
We designed the sliders so that a setting of `0` represents a **Realistic Baseline** (no extra bias injected). To find the exact $\sigma$ required for these baselines, we work the AUC formula backward using the inverse CDF ($\Phi^{-1}$):

1. **Set the Target AUC:**  
$$ \text{AUC}_{Target} = \Phi\left( \frac{1}{\sigma \sqrt{2}} \right) $$  

2. **Apply the Inverse CDF:**  
$$ \Phi^{-1}(\text{AUC}_{Target}) = \frac{1}{\sigma \sqrt{2}} $$  

3. **Solve for $\sigma$:** 
$$\sigma = \frac{1}{\Phi^{-1}(\text{AUC}_{Target}) \cdot \sqrt{2}}$$  
   

Using this logic:
* For **Global Feature Predictivity**, we target an inherent AUC of **0.90**. Since $\Phi^{-1}(0.90) \approx 1.28155$, we find that $\sigma_y \approx \mathbf{0.5518}$.
* For **Proxy/Group Separability**, we target an inherent separability AUC of **0.85**. Since $\Phi^{-1}(0.85) \approx 1.03643$, we find that $\sigma_s \approx \mathbf{0.6823}$.

> [!NOTE]
> You can also find these values empirically via a brute-force search script provided in [`find_sigmas.py`](find_sigmas.py).

As you slide a mechanism to `1` (Max Bias), the standard deviations ($\sigma$) are scaled to either artificially destroy the signal (increasing $\sigma$) or artificially create perfect separability (decreasing $\sigma$ to $0$), allowing you to measure the exact threshold where fairness breaks.

## Run Locally

You just need to install  [Quarto](https://quarto.org/docs/get-started/).

### Running the App
1. Clone the repository.
2. Open a terminal in the project root directory.
3. Run: 
   ```bash
   quarto preview index.qmd
   ```
4. Open the provided `localhost` URL in your browser.
